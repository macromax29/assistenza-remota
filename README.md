# Tech360 - versione interattiva

Questa versione aggiunge una richiesta guidata collegata a WhatsApp.

Prima di pubblicare, apri `script.js` e sostituisci `393331234567` con il tuo numero in formato internazionale, senza + e senza spazi.

Poi sostituisci nel repository GitHub Pages:
- index.html
- styles.css
- script.js

Dopo il commit, GitHub Pages aggiornera automaticamente il sito.
